# 超级小鲤鱼的个人主页

哈喽大家好，这里是一个梦想做出好内容的穷学生的个人主页，正在不断学习+搬砖完善中。。。 

## 阅读笔记

主页只展示个人介绍、代表作品与最新笔记入口。阅读目录位于 reading/index.html，每篇文章有独立路径；REA 源码笔记位于 reading/rea/index.html，图解保存在 assets/reading/rea/。文章引用固定提交，并区分源码阅读、教学示例和实际实验。

本地预览：在仓库根目录执行 python -m http.server 8765，打开 http://127.0.0.1:8765/。网站为纯静态 HTML/CSS/JavaScript，无需构建。

新增笔记时创建 reading/<slug>/index.html，在阅读目录和主页入口添加对应链接。文章交互与排版共享 reading.js、reading.css 和 styles.css。
