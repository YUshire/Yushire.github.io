# 余文豪的个人主页

水墨风格的计算机科学个人主页，展示研究方向、代表项目、论文、教育经历与联系方式。

## 页面内容

- 大模型推理与异构计算优化
- 机器学习、因果推断与数据挖掘
- 多目标优化与智能决策
- 论文、项目、教育经历与主要荣誉
- 可下载的个人简历

## 交互与视觉

- 黑白水墨与楷体排版，并提供夜墨主题
- 响应式桌面与移动端布局
- 项目分类筛选与论文摘要展开
- 水墨锦鲤鼠标：鱼身沿指针轨迹自然弯曲，静止时仅尾端轻摆
- 鱼尾产生短促的淡墨涟漪；触屏设备和“减少动态效果”模式自动使用系统指针

## 本地预览

在项目目录启动任意静态文件服务器：

```bash
python -m http.server 4173
```

然后访问 `http://127.0.0.1:4173/`。
