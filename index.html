01

MULTI-AGENT SYSTEM · LOCAL LLM DEPLOYMENT

MindBridge 多 Agent 心理支持与风险预警平台

基于开源框架复现并完善校园心理支持原型，贯通事件驱动的 Agent 协作、知识检索、多轮记忆与工具任务。完成 Qwen2.5-7B LoRA 微调、GGUF 量化与 Ollama 部署，并接入 Chroma、MySQL 和 Redis，验证真实聊天、流式输出和数据持久化链路。

已完成实验2,400 条四分类情绪样本，按 2,160 / 240 划分训练与验证集，完成 3 epoch、405 步训练。60 条本地检索用例全部命中至少一条相关结果，MRR 为 0.9556；检索平均延迟约 254 ms。

查看实现与评测口径 ＋
  • 协作与可追溯：通过 Runtime / Harness 统一管理输入脱敏、Agent 调用、报告落库和 run trace；使用任务板组织协作产物与风险处理流程。
  • 记忆与检索：Redis 保存短期记忆，MySQL 持久化消息与 trace；以 BGE-M3、Chroma 和 BM25 实现混合检索，结合历史窗口裁剪、摘要压缩和 Skill 加载组织上下文。
  • 训练与本地推理：完成 LoRA 权重合并、GGUF 转换、Q4_K_M 量化及 Ollama 接入；保留 adapter、训练配置、checkpoint 与文件哈希以支持复跑核验。
  • 评测范围：240 条合成验证样本上，微调模型严格输出正确分类标签的比例为 100%，主要反映标签格式遵循。100 条合成风险用例的系统准确率为 81%，高风险召回为 27/30；仍存在漏判，不能据此推断真实心理支持效果。
  • 工程验收：真实全栈检查 42/43 通过，保留一条风险误判；另完成 52 项回归测试及集成启动器。检索命中率采用测试集来源或关键词匹配口径，不等同于回答正确率。
  • Multi-Agent
  • Qwen2.5 / LoRA
  • Chroma / BGE-M3
  • Ollama

02

AGENT POST-TRAINING · OPEN-SOURCE REPRODUCTION

企业问答与购物 Agent 后训练实验系统

将企业客服问答与 ShopSimulator 购物仿真任务接入同一服务原型，结合意图路由、RAG、多轮记忆、工具调用和轨迹展示。在 Qwen3.5-2B 上完成动作级 LoRA SFT，并接入 veRL 验证 GRPO 在线采样、确定性规则奖励与有效参数更新。

当前进展使用 799 条训练轨迹、200 条验证轨迹，完成 3 epoch、300 步 SFT，并核验 adapter 合并权重。GRPO 已验证有效更新；完整训练、冻结 200 题三阶段对比及独立 Judge 评测尚未验收。

查看训练流程与实现边界 ＋
  • 路由与记忆：融合 LLM Few-shot、Embedding 相似度及关键词规则，以加权评分、低置信度澄清和异常降级分流请求；通过 Redis 与 ChromaDB 管理会话状态、知识、历史摘要和用户明确偏好。
  • 轨迹与 SFT：复用开源购物轨迹，按任务 ID 检查训练、验证、测试集交集；仅对 Agent 动作 Token 计算损失，屏蔽用户指令与环境页面，学习合法工具调用。
  • GRPO：在购物仿真环境在线采样，以品类、预算作为硬约束，对品牌、型号、功能与规格加权计分；过滤无效轨迹、跳过组内同奖励样本，并通过有界重采样获取有效学习信号。训练奖励与 LLM Judge 评分分开处理。
  • 评测与留存：已准备冻结测试任务、统一执行协议、轨迹及训练日志留存、数据哈希和权重合并核验；独立 Judge 的脚本与隔离检查已实现，最终评测待完成。
  • 集成范围：客服与购物共享服务入口、会话状态及轨迹展示；购物后训练作用于购物策略，客服预算状态到购物目标的转换仍需完善，当前定位为复现与实验原型。

  • Qwen3.5-2B
  • LoRA / SFT
  • veRL / GRPO
  • ShopSimulator

03

LEARNING PROJECT · TRANSFORMER FROM SCRATCH

从零实现 Transformer 语言模型预训练系统

参考 Stanford CS336，搭建从文本处理、byte-level BPE 与 Tokenizer 到 Decoder-only Transformer 训练和生成的完整链路。实现模型核心模块、单卡与双卡 DDP 训练，以对比实验分析模型规模对验证损失与困惑度的影响。

复现实验22.7M 参数基线训练 50,000 steps，Validation Loss 约为 2.80、PPL 约为 16.4；扩展至 35.2M 参数后分别降至 2.62 与 13.7，PPL 相对下降约 16.5%。

查看模型与训练实现 ＋
  • 数据：实现 BPE 训练及 Tokenizer 编解码，支持 UTF-8 字节回退、特殊 Token、流式编码和多进程分块；通过紧凑 Token ID 文件与 memmap 降低语料加载的内存占用。
  • 模型：实现 Linear、Embedding、RMSNorm、RoPE、因果多头注意力和 SwiGLU，采用 Pre-Norm 与残差结构，并实现交叉熵损失与 AdamW。
  • 训练：集成 warmup + cosine 学习率调度、梯度裁剪、checkpoint 恢复和 W&B 指标监控；比较 4 层与 8 层 Transformer、不同注意力头配置下的模型表现。
  • PyTorch
  • DDP
  • Tokenizer
  • Pre-training
