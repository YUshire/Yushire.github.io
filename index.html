LLM SYSTEMS · ASCEND NPU

Llama 大模型推理引擎移植与优化

基于华为昇腾 910/910B 与 CANN 完成全链路移植，通过权重常驻、算子融合、批量多头注意力和 strided KV Cache，将推理吞吐提升至 180.77 tok/s，达到 CPU 基线的 3.3 倍。

02

AGENTIC SYSTEM · POST-TRAINING & EVALUATION

面向企业服务与长程购物的智能 Agent 系统

构建面向企业知识问答与长程购物决策的统一 Agent 原型：以 RAG、意图路由和分层记忆承接多轮服务，以工具调用完成“搜索—参数核验—规格选择”链路，并设计轨迹数据构造、SFT / GRPO 后训练与冻结题集盲评流程，形成“知识检索—决策执行—质量评测”的可复现闭环。

实验结果在冻结的 200 道测试题上，严格成功率由 0% 提升至 SFT 60.5%、GRPO 62.0%，购买成功率最高达到 62.5%；平均奖励由 -0.11 提升至 0.52，非法工具调用拦截次数由 752 次降至 38 次。

  • Agentic RL
  • RAG
  • SFT / GRPO
  • LLM-as-Judge
↗
03

LEARNING PROJECT · TRANSFORMER FROM SCRATCH

从零实现 Transformer 语言模型预训练系统

参考 Stanford CS336，从 byte-level BPE、Tokenizer 与数据流开始，模块化实现 RMSNorm、RoPE、Causal Attention、SwiGLU、Cross-Entropy 和 AdamW，并搭建单卡及 DDP 训练、warmup + cosine 调度、checkpoint 恢复与 W&B 监控流程，以控制变量实验分析模型扩容与生成质量。

实验结果在双 RTX 3090 上完成 50,000 steps 训练；22.7M Baseline 的 Validation Loss 约为 2.80、PPL 约为 16.4，扩展至 35.2M 参数后分别降至 2.62 与 13.7，PPL 相对下降约 16.5%。

  • PyTorch
  • DDP
  • Tokenizer
  • Pre-training
